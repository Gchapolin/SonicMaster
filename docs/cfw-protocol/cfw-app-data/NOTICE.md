# Data files from the Sonicake CFW web app

Downloaded 2026-11-24 from https://pocketmaster-cfw.guitar-training-generator.com/app/assets/assets/data/
(the data the CFW web app ships alongside its code).

The CFW app's About dialog states it is a fork of SonicMaster (MIT License, Copyright (c) 2026 Andrii
Klaptsov) and that its "CFW additions (this fork, same MIT License)". These files are kept here as
reference for re-implementing the CFW features in this app, under that MIT license, with credit to the
Sonicake CFW project (https://pocketmaster-cfw.guitar-training-generator.com/).

Files new in the CFW app: amp_cab_info, cfw_chorus_models, cfw_eq_models, cfw_fx_models.
Files changed vs. this repo's app/assets/data: character_map, command_library, device_capabilities,
effect_library (14 new entries: DLY Float/Shake, cabs Mark 2x10/Ampg 4x10, User IR 6-10, User Profile 6-10),
effect_signatures, modules, value_reverse_lookup.
